# lanbook_pdf

Скачивает книгу с e.lanbook.com одним PDF-файлом. Заменяет старый постраничный
загрузчик SVG, который перестал работать после изменений на сайте.

## Требования

- Windows 10/11 (встроенный `curl.exe`) и Python 3.8+
- Если `curl` недоступен, скрипт использует `requests` (`pip install requests`)
- Доступ к сайту: при необходимости включите системный VPN/прокси

## Как пользоваться

1. Откройте книгу в читалке на e.lanbook.com под своим аккаунтом.
2. Нажмите F12, вкладка **Network**, обновите страницу (F5).
3. Найдите запрос `documentFile?base64=1&lms=&jwtToken=...`.
4. Правой кнопкой по нему: **Copy -> Copy URL**.
5. Сразу запустите (токен в адресе живёт недолго):

   ```powershell
   python lanbook_pdf.py
   ```

   и вставьте адрес. Или передайте его аргументом в кавычках:

   ```powershell
   python lanbook_pdf.py "https://reader.lanbook.com/api/v2/book/197763/documentFile?base64=1&lms=&jwtToken=..."
   ```

Можно запускать двойным кликом по `run.bat`. Результат сохраняется как
`book_<ID>.pdf` рядом со скриптом. Своё имя файла задаёт `--out имя.pdf`.

## Если что-то не работает

- **`schannel ... CRYPT_E_NO_REVOCATION_CHECK`**: скрипт уже добавляет
  `--ssl-no-revoke` для curl на Windows.
- **`schannel: failed to receive handshake` или `SSL EOF`**: сервер сбрасывает
  соединение. Включите системный VPN (не расширение браузера) или проверьте
  антивирус с проверкой HTTPS.
- **HTTP 401/403**: токен устарел, скопируйте адрес заново. Если не помогает,
  создайте `header.json` по образцу `header.json.example` и вставьте куки из
  заголовков того же запроса.
- **«Ответ сервера не похож на PDF»**: скрипт покажет начало ответа,
  обычно это сообщение об ошибке.

## Безопасность

- `jwtToken` в адресе и куки работают как пароль. Не публикуйте их и не
  присылайте никому. Не коммитьте `header.json` в репозиторий.
- После работы лучше выйти из аккаунта на сайте.
- Используйте скачанное только для личной учёбы, в рамках правил сервиса.
